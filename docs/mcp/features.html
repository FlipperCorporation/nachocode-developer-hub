제공 기능

🔔 최신화 일자: 2026-09-11

준비 중

nachocode MCP 서버의 기능 목록은 이후 업데이트로 계속 추가됩니다.

nachocode MCP 서버는 세 종류의 기능을 제공합니다.

종류역할개수
도구 (Tools)대화 중 AI 에이전트가 필요할 때 자동으로 호출하는 기능7개 (ChatGPT 계열에는 2개 추가)
리소스 (Resources)AI 에이전트가 직접 읽을 수 있는 원본 자료6개
프롬프트 (Prompts)자주 하는 작업을 단계별로 안내하는 대화 템플릿5개

도구는 정확한 원문이 꼭 필요한 곳에 집중합니다. SDK 타입 선언과 Open API 원본 스펙, 버전 호환·에러 코드·릴리즈 노트 비교, 그리고 앞으로 추가될 로그인 뒤의 앱·대시보드 작업입니다. 요금, 기능 설정 위치, 출시 절차, 자주 묻는 질문은 별도 도구 없이 nachocode_search_knowledge 검색으로 바로 찾을 수 있습니다.

지식 도구로 시작하여 추후 업데이트를 통해 푸시 발송, 빌드 요청, 푸시 내역 조회처럼 앱과 대시보드를 직접 다루는 작업 도구가 순차적으로 더해집니다.

범위는 추가 예정에서 확인할 수 있습니다.

공통 동작​

모든 도구는 아래 규칙을 따릅니다. 어떤 클라이언트에서 쓰든 같습니다.

  • 이름 규칙: 도구 이름은 nachocode_ 접두사로 시작합니다. 여러 MCP 서버를 함께 연결해도 어느 서버의 도구인지 바로 알 수 있습니다. ChatGPT 규격 도구 search·fetch만 예외이며, 이 둘은 ChatGPT에서만 보입니다.
  • 답변 언어: 질문한 언어로 답합니다. 문서 원문을 인용할 때는 한국어 원문을 그대로 보여 줍니다.
  • 근거 제시: 검색과 조회 결과에는 문서 URL(앵커 포함)이 함께 오므로 원문을 바로 확인할 수 있습니다.
  • 결과 형식: 짧은 요약과 전체 내용을 함께 돌려줍니다. 문서형 도구는 마크다운 본문과 섹션 목록을, 그 밖의 도구는 같은 내용을 정리한 데이터(JSON)도 함께 주므로 어떤 클라이언트에서도 내용을 확인할 수 있습니다.
  • 긴 문서: 기본 6,000자, 최대 16,000자 단위로 나눠 돌려주고 섹션 목록을 함께 주므로 필요한 부분만 이어서 읽을 수 있습니다.
  • 오류: 실패하면 오류 코드·메시지·해결 힌트를 돌려주고 연결은 유지합니다.

도구 (Tools)​

기반​

nachocode 도구를 통해 필요한 자료를 찾을 수 있습니다.
개발자 문서·릴리즈 노트뿐 아니라 자주 묻는 질문(FAQ), 기능별 설정 위치와 스토어 출시 체크리스트도 검색 결과로 나옵니다.

도구하는 일이렇게 물어보세요
nachocode_search_knowledge개발자 문서·SDK·릴리즈 노트·FAQ·기능 정보를 한 번에 검색“마케팅 푸시 야간 발송 조건이 뭐야?”
nachocode_get_document문서 본문이나 특정 섹션을 그대로 읽기“푸시 토큰 가이드에서 삭제 시점 부분 보여 줘”
nachocode_list_knowledge문서 목차(사이드바·카테고리·FAQ·기능 정보) 보기“SDK 문서에 어떤 네임스페이스가 있어?”

개발자용​

AI 코딩 도구 안에서 SDK·API 원본 레퍼런스를 바로 꺼내 쓰고, 버전 호환을 확인한 뒤 검증된 예제로 코드를 제안받습니다.

도구하는 일이렇게 물어보세요
nachocode_sdk_lookupSDK 메서드·타입의 시그니처와 문서 링크 확인“React로 푸시 토큰 등록·삭제 코드 작성해줘”
nachocode_get_api_referenceOpen API 요청·응답 형식, 한도, 서버 액션 비용, 에러 코드“POST /api/push/v2/users 요청 본문 예시 만들어 줘”
nachocode_get_release_notes버전별 변경 사항, 두 버전 사이의 차이“SDK 1.10.0에서 1.11.3으로 올리면 뭐가 바뀌어?”
nachocode_explain_error_code에러 코드의 의미·원인·조치“ERR-AB-PSS-92가 무슨 뜻이야?”

리소스 (Resources)​

AI 에이전트가 직접 읽을 수 있는 원본 자료입니다. 리소스는 사용자가 명시적으로 첨부하는 자료이며 대화 중 자동으로 쓰이지는 않습니다.
경로나 이름이 필요한 리소스는 클라이언트에서 자동완성을 지원합니다.

리소스 URI내용자동완성
nachocode://developer-docs/{path}개발자 허브 문서 본문(정제 마크다운). path는 /docs/ 이후 경로경로
nachocode://sdk/{namespace}.d.tsSDK TypeScript 타입 정의를 네임스페이스별로 나눈 것.namespace
nachocode://sdk/manifest.jsonSDK 네임스페이스·메서드·필요한 최소 버전 요약—
nachocode://openapi.jsonnachocode Open API의 OpenAPI 3.1 명세—
nachocode://glossarynachocode 용어 사전—
nachocode://index/manifest지식 인덱스의 출처 버전, 수집 시각, 빌드 시각, 문서 수—

프롬프트 (Prompts)​

자주 하는 작업을 단계별로 안내하는 대화 템플릿입니다.
인자는 실행 시 물어봅니다. 목록 인자는 쉼표로 구분해 적습니다.

프롬프트대상인자안내 내용
integrate_sdk개발자프레임워크, 언어, 사용할 기능(쉼표 구분)CDN 스크립트 삽입, initAsync 초기화, env.isApp() 가드, 초기화 이벤트 순서, 샌드박스 앱으로 확인하기, 기능별 다음 단계
implement_personal_push개발자프레임워크, 언어로그인 시 user.setUserId, 로그아웃 시 deleteUserId, 서버에서 POST /api/push/v2/users·/messages 호출까지 한 흐름으로 안내
implement_marketing_consent개발자방식(nachocode 내장 팝업 · 직접 구현), 프레임워크, 언어정보통신망법 기준의 마케팅·야간 수신 동의, 내장 팝업과 자체 팝업의 차이, push.setMarketingPreference 사용법
debug_push_not_received개발자·운영자플랫폼, 푸시 종류토큰 등록 → 알림 권한 → 앱소스 버전 → FCM 설정 → 샌드박스·운영 앱 불일치 → 마케팅 동의 순서로 원인을 좁히는 진단 체크리스트
migrate_sdk_version개발자현재 버전, 목표 버전, 트랙(SDK · Android · iOS)두 버전 사이의 릴리즈 노트를 모아 영향 범위, 수정할 코드, 앱 재빌드 필요 여부 정리

추가 예정​

추 후 업데이트를 통해 AI 에이전트가 로그인한 계정 권한 안에서 앱과 대시보드를 직접 다루는 작업 도구가 순차적으로 열립니다.
아래는 예정된 범위이며 도구 이름과 세부 동작은 출시 시 확정됩니다.

앱 작업​

nachocode Open API로 할 수 있는 일을 대화로 처리합니다.

  • 개인화 푸시 발송(유저 목록·메시지 목록), 토픽 푸시·전체 푸시 발송
  • 토픽 목록 조회, 토픽 구독·구독 해제, 푸시 토큰 삭제
  • 앱 유저 회원 탈퇴 처리, 마케팅 수신 동의 변경
  • 발송 전에 요청 본문을 미리 검증하기

대시보드 작업​

대시보드에서 하던 운영 작업을 대화로 처리합니다.

  • 앱 목록과 기본 정보, 개발자 설정 조회·변경
  • 빌드 요청과 빌드 이력, 강제 업데이트 설정
  • 푸시 전송 내역, 예약 푸시 목록과 예약 취소
  • API 키 조회·발급·연장, 웹훅 관리와 테스트·로그, 인앱 상품과 결제 로그
  • 통계(개요·유입·참여·유지), 멤버 목록과 초대, 외부 연동·마케팅 푸시·로딩 설정

안전 원칙​

작업 도구는 아래 원칙을 지킵니다.

  • 전체 발송, 토큰 삭제, 회원 탈퇴, 강제 업데이트 설정, 예약 취소, API 키 재발급처럼 되돌리기 어려운 작업은 실행 전에 사용자 확인을 거칩니다.
  • 발송 작업은 운영 앱인지 샌드박스 앱인지 환경을 명시해야 실행됩니다.
  • Secret Key, 웹훅 키 같은 비밀 값은 응답에서 마스킹됩니다. API Key·Secret Key는 AI 클라이언트에 노출되지 않고 nachocode 서버 안에서만 사용됩니다.
  • 결제·구독 변경, 앱 삭제, 멤버 제거, 계정 탈퇴, 저장된 비밀 값 조회는 MCP로 제공하지 않습니다.
