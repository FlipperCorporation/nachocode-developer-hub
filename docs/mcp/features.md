# 제공 기능 {#features}

> 🔔 **최신화 일자:** 2026-09-10

<!-- 2026-09-09 최초 생성 -->

:::caution 준비 중
기능 목록은 MCP 서버 출시 시점에 최종 확정되며, 이후 업데이트로 계속 추가됩니다.
:::

nachocode MCP 서버는 세 종류의 기능을 제공합니다.

| 종류                   | 역할                                                   | 개수 |
| ---------------------- | ------------------------------------------------------ | ---- |
| **도구** (Tools)       | 대화 중 AI 에이전트가 필요할 때 자동으로 호출하는 기능 | 17개 |
| **리소스** (Resources) | AI 에이전트가 직접 읽을 수 있는 원본 자료              | 10개 |
| **프롬프트** (Prompts) | 자주 하는 작업을 단계별로 안내하는 대화 템플릿         | 8개  |

문서·레퍼런스와 기능 정보를 정확하게 찾아 주는 **지식 도구**로 시작하여 추 후 업데이트를 통해  
푸시 발송, 빌드 요청, 푸시 내역 조회처럼 **앱과 대시보드를 직접 다루는 작업 도구**가 순차적으로 더해집니다.

범위는 [추가 예정](#upcoming)에서 확인할 수 있습니다.

## 공통 동작 {#common-behavior}

모든 도구는 아래 규칙을 따릅니다. 어떤 클라이언트에서 쓰든 같습니다.

- **이름 규칙**: 도구 이름은 `nachocode_` 접두사로 시작합니다. 여러 MCP 서버를 함께 연결해도 어느 서버의 도구인지 바로 알 수 있습니다. ChatGPT 규격 도구 `search`·`fetch`만 예외입니다.
- **답변 언어**: 질문한 언어로 답합니다. 문서 원문을 인용할 때는 한국어 원문을 그대로 보여 줍니다.
- **근거 제시**: 검색과 조회 결과에는 문서 URL(앵커 포함)이 함께 오므로 원문을 바로 확인할 수 있습니다.
- **결과 형식**: 구조화된 데이터와 3줄 이내 요약을 함께 돌려줍니다. 목록은 20건씩 나누어 제공하고 다음 페이지 커서를 줍니다.
- **긴 문서**: 한 번에 다 주지 않고 섹션 목록을 먼저 보여 준 뒤 필요한 섹션만 다시 읽도록 안내합니다. 본문은 기본 6,000자, 최대 16,000자 단위입니다.
- **오류**: 실패하면 오류 코드·메시지·해결 힌트를 돌려주고 연결은 유지합니다.

## 도구 (Tools) {#tools}

### 공통 {#tools-common}

nachocode에 관한 질문이면 무엇이든 먼저 이 도구들로 자료를 찾습니다.

| 도구                         | 이럴 때 씁니다                                                   | 입력 → 결과                                                                                                                                                                                                                                     |
| ---------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nachocode_search_knowledge` | nachocode 관련 질문에 답할 자료를 찾을 때. 대부분 가장 먼저 호출 | 질문, 검색 범위(개발자 문서·사용자 가이드·블로그·요금과 기능 정보·SDK·릴리즈 노트), 독자 힌트(개발자·운영자), 최대 건수 → 관련 문서 조각 목록. 각 항목에 제목 경로, 앵커가 포함된 URL, 발췌문, 관련도, SDK·앱소스 버전 배지, 갱신일이 담깁니다. |
| `nachocode_get_document`     | 검색 결과의 본문 전체나 특정 섹션을 읽을 때                      | 문서 ID 또는 URL, 섹션 앵커, 최대 글자 수 → 정제된 마크다운 본문. 안내 상자, 버전 배지, 이미지 설명이 보존되고 갱신일과 출처가 함께 옵니다. 긴 문서는 섹션 목록을 먼저 돌려줍니다.                                                              |
| `nachocode_list_knowledge`   | 어떤 문서가 있는지 목차부터 보고 싶을 때                         | 출처, 경로 → 문서 트리. 개발자 문서는 사이드바 구조, 사용자 가이드와 블로그는 카테고리, 요금·기능·출시·FAQ는 주제, SDK는 네임스페이스, 릴리즈 노트는 플랫폼·버전 단위로 보여 줍니다.                                                            |
| `nachocode_lookup_glossary`  | 용어의 뜻이 헷갈릴 때                                            | 용어 → 정의, 관련 용어, 관련 문서. 예: 앱 키·API 키·Secret 키의 차이, 앱소스 버전·SDK 버전·앱 버전의 차이, 샌드박스 앱, 서버 액션, 토픽, 나쵸 링크, 강제 업데이트                                                                               |

### 앱 운영자용 {#tools-operator}

개발 지식 없이도 요금, 기능 설정, 출시 준비를 대화로 진행할 수 있게 돕습니다.

| 도구                             | 이럴 때 씁니다                                      | 입력 → 결과                                                                                                                                                                                                                                                                                   |
| -------------------------------- | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nachocode_get_pricing_plans`    | 플랜 구성과 가격, 포함 서비스를 정확히 알고 싶을 때 | 구분(구독·파트너·엔터프라이즈·전체), 결제 주기(월·연·평생) → 플랜별 이름, 가격, 연 결제 할인, 월 사용량, 포함 기능, 추천 대상 문구 원문, 연 결제 시 포함 서비스, 출시 대행 옵션, 정부지원사업 안내, 문의 경로. 기준일과 원문 URL이 함께 옵니다. 추천 판단은 하지 않습니다.                    |
| `nachocode_get_feature_guide`    | 특정 기능을 어떻게 켜고 설정하는지 알고 싶을 때     | 기능 이름(푸시, 마케팅 푸시, 스플래시, 탭바, 시스템 바, 로딩, 딥링크, 인앱 결제, 빌드, 샌드박스, 강제 업데이트, 통계, 웹훅, 멤버, 외부 연동) → 기능 설명, 필요한 플랜, 대시보드 경로(예: 메시지 › 푸시 알림 › 설정), 사용자 가이드·개발자 문서·블로그 링크, 필요한 SDK·앱소스 버전, 흔한 문제 |
| `nachocode_get_launch_checklist` | 스토어 출시를 준비할 때                             | 플랫폼(Android·iOS·둘 다), 출시 대행 이용 여부 → 웹사이트 점검 → 스토어 계정·준비 → 빌드 → 심사 제출 → 거절 대응 순서의 체크리스트. 단계마다 사용자 가이드와 개발자 문서 링크가 붙습니다.                                                                                                     |
| `nachocode_get_faq`              | 자주 묻는 질문의 공식 답을 찾을 때                  | 주제(요금·출시·푸시·빌드·연동·계정·전체), 검색어 → 질문·답변 원문과 출처(마케팅 사이트 FAQ, 개발자 허브 FAQ, 도움말 센터 고객 센터 글)                                                                                                                                                        |
| `nachocode_get_dashboard_map`    | “이 설정은 대시보드 어디에 있나요?”에 답할 때       | 화면 이름 → 대시보드 메뉴 트리, 각 화면이 하는 일, 화면별 가이드 링크                                                                                                                                                                                                                         |

### 개발자용 {#tools-developer}

AI 코딩 도구 안에서 SDK·API 레퍼런스를 바로 꺼내 쓰고, 버전 호환을 확인한 뒤 코드를 제안받습니다.

| 도구                           | 이럴 때 씁니다                                          | 입력 → 결과                                                                                                                                                                                                                                                                                |
| ------------------------------ | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `nachocode_sdk_lookup`         | SDK 메서드의 정확한 시그니처와 조건을 확인할 때         | 네임스페이스, 메서드 → 시그니처, 파라미터·반환 타입(타입 정의 원문), 추가된 SDK 버전, 필요한 앱소스 버전(Android·iOS), 지원 플랫폼, 서버 호출 여부, 문서 URL, 예제, 알려진 주의점(예: 웹 환경에서는 콜백이 조용히 실패)                                                                    |
| `nachocode_sdk_check_compat`   | 지금 쓰는 SDK·앱소스 버전에서 되는지 확인할 때          | 메서드 목록, 사용 중인 SDK 버전, Android·iOS 앱소스 버전 → 메서드별 지원 여부, 필요한 최소 버전, deprecated 여부와 대체 메서드, 앱 재빌드 필요 여부                                                                                                                                        |
| `nachocode_sdk_snippet`        | 검증된 코드 템플릿으로 빠르게 시작할 때                 | 시나리오(초기화, 푸시 토큰 생명주기, 마케팅 동의, 생체 인증, 안전 영역, 인앱 결제, 딥링크 처리, 소셜 로그인, 로컬 푸시, QR 스캐너), 프레임워크(Vanilla·React·Next·Vue), 언어(JS·TS) → 템플릿 코드, 설명, 전제 조건(앱소스 버전, 대시보드 설정)                                             |
| `nachocode_get_api_reference`  | Open API 요청을 만들거나 응답을 해석할 때               | 오퍼레이션(예: `POST /api/push/v2/users`), 생략하면 전체 목록 → 요청·응답 스키마, 한도, 에러 코드, cURL 예제, 서버 액션 비용. 개발자 허브의 [OpenAPI 3.1 명세](https://github.com/FlipperCorporation/nachocode-developer-hub/blob/main/openapi/nachocode-open-api.yaml)를 그대로 읽습니다. |
| `nachocode_get_release_notes`  | 버전별 변경 사항이나 두 버전 사이의 차이를 알고 싶을 때 | 플랫폼(SDK·Android·iOS), 버전 또는 범위(from·to), 최신 여부 → 릴리즈 노트 요약과 원문 링크. 범위를 주면 두 버전 사이 변경을 모아 정리하므로 업그레이드 계획에 쓸 수 있습니다.                                                                                                              |
| `nachocode_explain_error_code` | 에러 코드가 무슨 뜻인지, 어떻게 고치는지 알고 싶을 때   | 에러 코드(예: `ERR-AB-PSS-92`) → 의미, 원인, 조치, 관련 문서. 개발자 허브 API 문서의 에러 표와 SDK 타입 정의의 설명을 출처로 씁니다.                                                                                                                                                       |

### ChatGPT 커넥터·딥 리서치용 {#tools-chatgpt}

ChatGPT 커넥터와 딥 리서치는 `search`·`fetch`라는 정해진 이름과 형식의 도구만 호출합니다. 두 도구는 공통 도구를 감싼 얇은 어댑터이며, 다른 클라이언트에서 호출해도 정상 결과를 돌려줍니다.

| 도구     | 입력    | 결과                                                                                                                                       |
| -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `search` | 검색어  | 결과 목록(ID, 제목, 인용용 URL). 내부적으로 `nachocode_search_knowledge`를 전 출처 대상으로 실행합니다.                                    |
| `fetch`  | 결과 ID | 문서 본문(ID, 제목, 본문, URL, 출처·갱신일). 내부적으로 `nachocode_get_document`를 실행하며 16,000자를 넘으면 이어 읽을 섹션을 안내합니다. |

## 리소스 (Resources) {#resources}

AI 에이전트가 직접 읽을 수 있는 원본 자료입니다. Claude Code에서는 `@nachocode:` 접두어로 대화에 첨부합니다. 경로나 이름이 필요한 리소스는 클라이언트에서 **자동완성**을 지원합니다.

| 리소스 URI                          | 내용                                                                                   | 자동완성  |
| ----------------------------------- | -------------------------------------------------------------------------------------- | --------- |
| `nachocode://developer-docs/{path}` | 개발자 허브 문서 본문(정제 마크다운). `path`는 `/docs/` 이후 경로                      | 경로      |
| `nachocode://user-guide/{slug}`     | 사용자 가이드(docs.nachocode.io) 글 스냅샷                                             | slug      |
| `nachocode://blog/{slug}`           | nachocode 블로그 글 스냅샷(고객 사례·제품 소식)                                        | slug      |
| `nachocode://sdk/{namespace}.d.ts`  | SDK TypeScript 타입 정의를 네임스페이스별로 나눈 것. 전체 파일은 한 번에 읽기엔 큽니다 | namespace |
| `nachocode://sdk/manifest.json`     | SDK 네임스페이스·메서드·필요한 최소 버전 요약                                          | —         |
| `nachocode://openapi.json`          | nachocode Open API의 OpenAPI 3.1 명세                                                  | —         |
| `nachocode://product/plans`         | 요금제·플랜 사실 정보                                                                  | —         |
| `nachocode://product/features`      | 기능 카탈로그(필요한 플랜, 대시보드 경로, 문서 링크)                                   | —         |
| `nachocode://glossary`              | nachocode 용어 사전                                                                    | —         |
| `nachocode://index/manifest`        | 지식 인덱스의 출처 버전, 수집 시각, 빌드 시각, 문서 수                                 | —         |

## 프롬프트 (Prompts) {#prompts}

자주 하는 작업을 단계별로 안내하는 대화 템플릿입니다. Claude Code에서는 `/mcp__nachocode__<prompt>`로 실행하며, 인자는 실행 시 물어봅니다.

| 프롬프트                      | 대상          | 인자                                  | 안내 내용                                                                                                                   |
| ----------------------------- | ------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `integrate_sdk`               | 개발자        | 프레임워크, 언어, 사용할 기능 목록    | CDN 스크립트 삽입, `initAsync` 초기화, `env.isApp()` 가드, 초기화 이벤트 순서, 샌드박스 앱으로 확인하기                     |
| `implement_personal_push`     | 개발자        | 프레임워크                            | 로그인 시 `user.setUserId`, 로그아웃 시 `deleteUserId`, 서버에서 `POST /api/push/v2/users` 호출까지 한 흐름으로 안내        |
| `implement_marketing_consent` | 개발자        | 방식(nachocode 내장 팝업 · 직접 구현) | 정보통신망법 기준의 마케팅·야간 수신 동의, 내장 팝업과 자체 팝업의 차이, `push.setMarketingPreference` 사용법               |
| `debug_push_not_received`     | 개발자·운영자 | 플랫폼                                | 토큰 등록 → 알림 권한 → 앱소스 버전 → FCM 설정 → 샌드박스·운영 앱 불일치 → 마케팅 동의 순서로 원인을 좁히는 진단 체크리스트 |
| `migrate_sdk_version`         | 개발자        | 현재 버전, 목표 버전                  | 두 버전 사이의 릴리즈 노트를 모아 영향 범위, 수정할 코드, 앱 재빌드 필요 여부 정리                                          |
| `compare_plans`               | 운영자        | 필요한 기능 목록(선택)                | 플랜별 가격·사용량·포함 서비스·출시 대행 옵션을 사실 기준 비교표로 정리하고 문의 경로 안내. 추천 결론은 내지 않음           |
| `launch_app_step_by_step`     | 운영자        | 플랫폼                                | 출시 체크리스트를 바탕으로 단계별 안내. 각 단계의 대시보드 경로와 가이드 링크 포함                                          |
| `setup_feature`               | 운영자        | 기능 이름                             | 기능 가이드와 대시보드 지도를 바탕으로 설정 절차 안내                                                                       |

## 추가 예정 {#upcoming}

nachocode 계정 로그인(OAuth 2.1)이 추가되면, AI 에이전트가 로그인한 계정 권한 안에서 앱과 대시보드를 직접 다루는 작업 도구가 순차적으로 열립니다. 아래는 예정된 범위이며 도구 이름과 세부 동작은 출시 시 확정됩니다.

### 앱 작업 {#upcoming-app}

nachocode Open API로 할 수 있는 일을 대화로 처리합니다.

- 개인화 푸시 발송(유저 목록·메시지 목록), 토픽 푸시·전체 푸시 발송
- 토픽 목록 조회, 토픽 구독·구독 해제, 푸시 토큰 삭제
- 앱 유저 회원 탈퇴 처리, 마케팅 수신 동의 변경
- 발송 전에 요청 본문을 미리 검증하기

### 대시보드 작업 {#upcoming-dashboard}

대시보드에서 하던 운영 작업을 대화로 처리합니다.

- 앱 목록과 기본 정보, 개발자 설정 조회·변경
- 빌드 요청과 빌드 이력, 강제 업데이트 설정
- 푸시 전송 내역, 예약 푸시 목록과 예약 취소
- API 키 조회·발급·연장, 웹훅 관리와 테스트·로그, 인앱 상품과 결제 로그
- 통계(개요·유입·참여·유지), 멤버 목록과 초대, 외부 연동·마케팅 푸시·로딩 설정

### 안전 원칙 {#upcoming-safety}

작업 도구는 아래 원칙을 지킵니다.

- 전체 발송, 토큰 삭제, 회원 탈퇴, 강제 업데이트 설정, 예약 취소, API 키 재발급처럼 되돌리기 어려운 작업은 **실행 전에 사용자 확인**을 거칩니다.
- 발송 작업은 운영 앱인지 샌드박스 앱인지 **환경을 명시**해야 실행됩니다.
- Secret Key, 웹훅 키 같은 비밀 값은 응답에서 **마스킹**됩니다. API Key·Secret Key는 AI 클라이언트에 노출되지 않고 nachocode 서버 안에서만 사용됩니다.
- 결제·구독 변경, 앱 삭제, 멤버 제거, 계정 탈퇴, 저장된 비밀 값 조회는 **MCP로 제공하지 않습니다.**
