# Release: ver.1.8.5 (2025-12-23)

> 🔔 **배포 일자:** 2025-12-23

nachocode iOS App Source **1.8.5** 버전이 반영되었습니다.

이번 업데이트 **ver.1.8.5**에서는 일부 버그가 수정되었습니다.

## 개선 및 수정 사항

- **버그 수정**: 앱 업데이트 시 내부 쿠키로 인해 발생하던 문제를 해결하기 위해, 업데이트 과정에서 쿠키 제거 로직을 추가했습니다.

## 업데이트 적용 방법

nachocode iOS AppSource **ver.1.8.5**의 변경 사항을 앱에 반영하려면 아래 경로에서 신규 버전의 앱을 다시 빌드하여 적용 가능합니다.
