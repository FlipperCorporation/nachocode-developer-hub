# Release: ver.1.11.1 (2026-07-23)

import { ThumbnailImage } from '@site/src/components/common/image/thumbnail-image';

<ThumbnailImage src='/img/docs/releases/release_note_android_detail.png'/>

> 🔔 **배포 일자:** 2026-07-23

nachocode Android App Source **1.11.1** 버전이 반영되었습니다.

이번 업데이트 **ver.1.11.1**에서는 구글 정책 변경에 따라 일부 라이브러리 버전이 업데이트되었습니다.

## 개선 및 수정 사항

- **인앱 결제** : 구글 정책에 따라 인앱 결제 라이브러리 버전이 8.0.0에서 9.1.0으로 업데이트되었습니다.

## 업데이트 적용 방법

nachocode Android AppSource **ver.1.11.1**의 변경 사항을 앱에 반영하려면 아래 경로에서 신규 버전의 앱을 다시 빌드하여 적용 가능합니다.
