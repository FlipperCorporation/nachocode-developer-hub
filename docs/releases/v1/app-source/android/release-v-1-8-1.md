# Release: ver.1.8.1 (2025-11-06)

import { ThumbnailImage } from '@site/src/components/common/image/thumbnail-image';

<ThumbnailImage src='/img/docs/releases/release_note_android_detail.png'/>

> 🔔 **배포 일자:** 2025-11-06

nachocode Android App Source **1.8.1** 버전이 반영되었습니다.

이번 업데이트 **ver.1.8.1**에서는 일부 버그가 수정되고 성능이 개선되었습니다.

## 개선 및 수정 사항

- **성능 개선**: 성능 개선을 위해 내부 코드의 일부 로직이 수정되었습니다.
- **기능 개선**: 내비게이션바, 상태바 디자인을 각각 변경 및 제어할 수 있도록 기능이 개선되었습니다.

## 업데이트 적용 방법

nachocode Android AppSource **ver.1.8.1**의 변경 사항을 앱에 반영하려면 아래 경로에서 신규 버전의 앱을 다시 빌드하여 적용 가능합니다.
