# Release: ver.1.8.3 (2025-12-10)

import { ThumbnailImage } from '@site/src/components/common/image/thumbnail-image';

<ThumbnailImage src='/img/docs/releases/release_note_android_detail.png'/>

> 🔔 **배포 일자:** 2025-12-10

nachocode Android App Source **1.8.3** 버전이 반영되었습니다.

이번 업데이트 **ver.1.8.3**에서는 일부 버그가 수정되고 다운로드 기능이 개선되었습니다.

## 개선 및 수정 사항

- **버그 수정**: 웹뷰에서 영상 재생 시 발생하는 버그를 일부 수정했습니다.
- **기능 개선**: Blob방식의 다운로드를 지원하도록 개선되었습니다.

## 업데이트 적용 방법

nachocode Android AppSource **ver.1.8.3**의 변경 사항을 앱에 반영하려면 아래 경로에서 신규 버전의 앱을 다시 빌드하여 적용 가능합니다.
